# NCM811 ISC Detection

CSV-upload-only Flask app, arranged for VS Code:

```text
NCM811_ISC_APP/
├── backend/
│   └── app.py
├── frontend/
│   ├── templates/
│   │   └── index.html
│   └── static/
│       └── style.css
├── demo_frontend_upload.csv
└── requirements.txt
```

## Run in VS Code

1. Open this `NCM811_ISC_APP` folder in VS Code.
2. Install `requirements.txt` in the selected Python environment.
3. Place the notebook-exported files in `backend/`:
   - `NCM811_final_ISC_model.joblib`
   - `isc_feature_columns.joblib`
4. Run `backend/app.py` and visit `http://127.0.0.1:5000`.
5. Upload `demo_frontend_upload.csv` to check the upload and prediction flow.

The demo CSV contains synthetic values for interface testing only. The model files are generated by the Colab notebook and are not included in this bundle.
